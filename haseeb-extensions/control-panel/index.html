Publish ON/OFF changes

The extension checks a small signed file that you host on your website. Turning someone OFF changes this file; upload the new one and they are locked out within about 10 minutes.

How to host it on your own site (one time)
  1. In Hostinger hPanel open File Manager and create a folder inside public_html, for example lf.
  2. Press Download status.json here and upload it into that folder.
  3. Open https://your-site.com/lf/status.json in the browser. You should see text starting with {"v":1,"token":…}.
  4. Paste that full address into the Status URL box above, then download license-public.js again (Setup) and put it in the extension folder.
  5. Each time you turn someone ON or OFF: download status.json again and upload it over the old one (same name).

The file is public but signed and holds only random ids (no emails). Do not let a cache plugin or Cloudflare cache it for long. If the file can’t be reached, customers keep working for up to 72 hours after their last successful check.

Setup: keys, extension file and backup
1
Your keys

Use the keys you already have, so existing licenses keep working. Only generate new keys if you are starting fresh: new keys make every old license stop working.

2
Extension file

Download this file and copy it into the extension folder, replacing the existing license-public.js. Then reload the extension. It contains only your public key.

3
Backup

Your customer list is stored in this browser only. Download a backup now and then, and use Restore to move it to another browser or after clearing data.
